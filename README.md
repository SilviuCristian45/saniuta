# Săniuța la vale

Joc multiplayer în browser: curse cu săniuțe de lemn pe o pârtie din Carpați, la apus și noaptea,
printre brazi, pietre, trambuline și bulgări. Până la 6 jucători, intri cu un cod sau joci offline cu boți.

În lucru. Pornire locală (Node ≥ 22.12):

```bash
npm install
npm run dev     # http://localhost:5175
npm test
```
